# Timer

Тёмное Android-приложение: таймер, который считает время до твоей даты смерти.

## Что происходит на экране

1. При открытии по центру висят приглушённые нули: **`0 лет : 0 месяцев : 0 дней`**.
2. Внизу — кнопка **«Дата смерти»**.
3. По нажатию барабаны раскручиваются, как в казино, и **останавливаются по одному**
   (слева направо, с лёгким «щёлком» на место).
4. Когда все встали — **внутри контуров цифр** снизу вверх волнами набирается
   **тёмная кровь**. Снаружи букв ничего не закрашивается — фон остаётся чистым.
5. Кнопка плавно превращается в **«Ты умрёшь через»**, и под цифрами включается
   секундный отсчёт, который **тикает назад**.

### Особенности реализации

- **Один ряд цифр.** Окно барабана — ровно одна высота цифры, соседние цифры
  ленты в кадр не попадают.
- **Кровь только в буквах.** Контуры всех символов собираются в `Path` через
  `Paint.getTextPath`, затем `canvas.clipPath(glyphPath)` и `canvas.clipPath(waterPath)`
  дают пересечение — заливка видна исключительно внутри глифов ниже уровня волны.
- **Живая волна.** Поверхность — сумма двух синусоид с разными амплитудами и
  скоростями; фазы гонит бесконечный аниматор, амплитуда медленно «дышит».
- **Склонения.** Подписи меняются вместе с числами: `1 год` / `2 года` / `5 лет`.


## Сборка APK

APK собирается автоматически через GitHub Actions — компилятор на телефоне не нужен.

1. Открой вкладку **Actions**
2. Выбери workflow **Build Timer APK**
3. Нажми **Run workflow** (или просто запушь в `main`)
4. Скачай артефакт **timer-debug-apk** из успешного прогона

## Структура

```
app/src/main/java/com/telega/timer/
  MainActivity.java     — экран и сценарий
  DeathClockView.java   — барабаны, вращение, волны, красная заливка
  MorphButton.java      — кнопка с плавной сменой текста
.github/workflows/
  build-apk.yml         — сборка APK
```

## Технические детали

- **Чистый Android SDK**, без AndroidX и без внешних зависимостей — вся
  графика рисуется на `Canvas`.
- Минимальная версия: Android 7.0 (API 24), целевая: API 35.
- Ориентация зафиксирована — портрет.
- Отсчёт считается от абсолютного времени, поэтому не накапливает ошибку.
