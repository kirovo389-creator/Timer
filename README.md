# Timer

Тёмное Android-приложение: таймер, который считает время до твоей даты смерти.

## Что происходит на экране

1. При открытии по центру висит приглушённый таймер `00:00:00`.
2. Внизу — кнопка **«Дата смерти»**.
3. По нажатию барабаны раскручиваются, как в казино, и **останавливаются по одному**.
4. Когда все встали — снизу **волнами набирается красно-тёмная жидкость**,
   и цифры сквозь неё становятся красными.
5. Кнопка плавно превращается в **«Ты умрёшь через»**, и таймер начинает
   **тикать назад** каждую секунду.

## Сборка APK

APK собирается автоматически через GitHub Actions — компилятор на телефоне не нужен.

1. Открой вкладку **Actions**
2. Выбери workflow **Build Timer APK**
3. Нажми **Run workflow** (или просто запушь в `main`)
4. Скачай артефакт **timer-debug-apk** из успешного прогона

## Структура

```
app/src/main/java/com/telega/timer/
  MainActivity.java     — экран и сценарий
  DeathClockView.java   — барабаны, вращение, волны, красная заливка
  MorphButton.java      — кнопка с плавной сменой текста
.github/workflows/
  build-apk.yml         — сборка APK
```

## Технические детали

- **Чистый Android SDK**, без AndroidX и без внешних зависимостей — вся
  графика рисуется на `Canvas`.
- Минимальная версия: Android 7.0 (API 24), целевая: API 35.
- Ориентация зафиксирована — портрет.
- Отсчёт считается от абсолютного времени, поэтому не накапливает ошибку.
